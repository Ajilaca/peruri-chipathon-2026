# Laporan PDF

Satu laporan per fase dan satu laporan lengkap. Semua dibuat dari skrip di [`../../scripts/build/`](../../scripts/README.md)
(`build_*report.py`), jadi isinya mengikuti `docs/results/` dan `evidence/`. Laporan tidak ditulis tangan.

| File | Isi |
|---|---|
| `CHIPATON_COMPLETE_REPORT.pdf` | semua fase 0 sampai 9M, 8 halaman (`build_complete_report.py`) |
| `CHIPATON_Phase4_Report.pdf` ... `Phase9M_Report.pdf` | laporan per fase yang punya skrip pembangun |
| `CHIPATON_Phase0_Report.pdf` ... `Phase3_Report.pdf` | laporan lama; tidak ada skrip pembangun, teksnya masih menyebut path sebelum penataan ulang |

Laporan berformat PDF, bukan Markdown. Nama file tidak memakai tanggal.
