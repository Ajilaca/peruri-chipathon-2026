# Phase 5M, step S6: INTT without the scaling pass — test plan and adoption rule

Written 2026-10-02, **before any S6 RTL and before any S6 measurement** (CRG-4). Scope and rules: ADR 0017 (Accepted). Base
configuration: C4b-B (Barrett, ADR 0013 Accepted), `rtl/ntt/ntt_core_c4b_b.sv`, P = 6, cuts as C4b-B. Labels: MEASURED,
INFERENCE, ESTIMATE, NOT MEASURED.

## 1. The change (one change)
FIPS 203 Algorithm 10 runs 7 Gentleman-Sande layers and then multiplies every coefficient by 3303 (= 128^-1 mod q). C4b-B does the
multiplication as a separate pass over 256 addresses (`S_SCALE`, one extra multiplier, 256 cycles). S6 removes that pass by halving
in every layer (3303 = 2^-7 mod q and the INTT has 7 layers):

| | per INTT butterfly, inputs a, b < q | constants |
|---|---|---|
| FIPS 203 / C4b-B | a' = (a + b) mod q;  b' = (zeta * (b - a)) mod q | scaling pass afterwards: x * 3303 mod q |
| S6 | a' = half_mod((a + b) mod q);  b' = (zeta' * (b - a)) mod q, zeta' = zeta * 1665 mod q | none; table of zeta' generated by script |

with `half_mod(x) = (x + (x[0] ? q : 0)) >> 1` for x in [0, q). NTT mode is unchanged (same ROM entries, same butterfly equations).
The core loses the `S_SCALE` state, the scaling multiplier and its Barrett reducer; INTT then has the same schedule as NTT.

### Equivalence argument (the mathematics is not changed, C1)
1. q is odd, so 2 has an inverse mod q: 2 * 1665 = 3330 = 1 (mod q). For x in [0, q), x/2 mod q is x/2 if x is even and (x + q)/2 if x
   is odd; both are < q (x < q gives (x + q)/2 < q), so `half_mod` is exactly multiplication by 2^-1 mod q on [0, q).
2. zeta * (b - a) * 2^-1 = (zeta * 1665 mod q) * (b - a) (mod q), so the b' output of the halved butterfly is 2^-1 times the standard b'.
3. Hence one halved layer equals the standard layer multiplied by 2^-1 (a linear map over Z_q times a scalar). Seven layers compose to
   2^-7 times the standard unscaled INTT. 128 * 3303 = 422,784 = 127 * 3329 + 1, so 2^-7 = 128^-1 = 3303 (mod q) and the result equals
   Algorithm 10 including its final line, for every input in [0, q)^256.
4. Value ranges: all stored values stay in [0, q) (half_mod, add_mod, the reducer output), so the operand contract D6 of the reducer
   ([0, q) x [0, q), ADR 0011) is unchanged.
Checked, not assumed: sections 3 V2-V7.

## 2. Corner cases (enumerated before the tests)
- half_mod: x = 0, 1, 2, q-2, q-1 (odd/even edge), every x in [0, q) exhaustively (3,329 values).
- INTT inputs: all 256 unit vectors e_i; all 256 vectors (q-1) * e_i; all-zero; all-(q-1); alternating 0 / q-1; all-1; ramp 0..255 mod q;
  1,000 random vectors in the golden test; 100 random + the Phase 4 corner polynomials in the RTL test (unchanged test of Phase 4).
- ROM: every zeta' entry for the 127 indices the INTT addresses, at layer boundaries (indices 127, 64, 63, 32, 31, 16, 15, 8, 7, 4, 3, 2, 1).
- Schedule: unchanged from C4b-B apart from the removed scaling pass (hazard scoreboard of Phase 4 reused, 0 violations required).

## 4. Adoption rule (fixed before measuring)
S6 (revision `M6`, seeds 1-6) is adopted as the base for S7 only if **all** hold:
1. correct: V1-V9 PASS, both simulators, V7 and the V2/V3 negative controls fail as required;
2. cycles constant and exactly NTT 119 / INTT 119 (the INTT scaling pass is gone; INTT = NTT cycles);
3. NTT-core ALM <= 12,573 at every seed, and timing met at 40.000 ns at every seed (worst setup >= 0, worst hold >= 0);
4. ADR 0012 against the previous step C4b-B at its median Fmax of seeds 1-6 (34.515 MHz; t_NTT = 3.448 us, t_INTT = 10.865 us,
   `evidence/phase05/5b/selection_worksheet.md`): with F = median over seeds 1-6 of the lowest slow-corner
   Fmax of M6, **t_NTT = 119 / F < 3.448 us and t_INTT = 119 / F < 10.865 us**.
Notes fixed now, so they cannot be argued after the measurement:
- t_INTT improves from 375 to 119 cycles by construction (INFERENCE); the binding part of condition 4 is the NTT part, i.e.
  F > 34.515 MHz, because NTT mode is unchanged in cycles. That part is decided by measured Fmax, which varies with the seed by about
  +-0.7 MHz (C4b-B 33.46-34.84 MHz): a loss there is possible with no change to the NTT path.
- No tolerance is added to condition 4. If M6 fails only because of the NTT part, M6 is reported as measured and **not adopted by the
  rule**; whether another rule applies is a new decision of the team (C5), not made here.
- If M6 is not adopted, S7 is not started until the team decides the base (C4b-B or M6).

## 5. Expectation (ESTIMATE, written before measuring; only a compile can tell)
- Cycles: INTT 375 -> 119 (schedule arithmetic: 7 layers x 16 cycles + 1 + P = 119, as the NTT; the scaling pass of 256 cycles disappears).
- DSP: 18 -> 16 expected (scaling multiplier removed). ALM: unknown sign. Removed: one reducer and the scale datapath. Added: 8 `half_mod`
  units and a 256-entry twiddle ROM per lane instead of 128 entries. Registers: roughly unchanged.
- Fmax: the INTT a-path moves `half_mod` to the write segment (more slack than the read segment, MEASURED slack of C4b-B: write segment
  17.1 ns vs read segment 11.0 ns at 40 ns), so no Fmax loss is expected from it; the ROM select on the zeta path is not expected to be critical.

## 6. Not covered

- The INTT of values outside [0, q) is not specified (the host interface writes 12-bit values; the golden and tests use [0, q)).
- Other seeds than 1-6, other constraints than 40.000 ns (a 20 ns information compile belongs to S8).
